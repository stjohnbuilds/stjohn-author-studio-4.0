# InDesign Export Test Pack

## Goal

Create a small, safe test pack Marie can place into InDesign and run
through the existing Quill & Ink InDesign exporter.

## Steps

1. Generate a short manuscript DOCX with unique phrases for the app
   exporter to find.
2. Generate matching sample Quill annotations and run them through
   `buildInDesignJsx`, the real app exporter.
3. Export a CSV from the same sample project for comparison.
4. Render-check the DOCX so the file opens and has usable pages.
5. Re-check the source goals before handing off.

## Verification

- DOCX exists and renders to preview PNGs.
- JSX is generated by the app exporter, not hand-written.
- CSV contains the same sample annotations.
- Output files are kept separate from real save data.
